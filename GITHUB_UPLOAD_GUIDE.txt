================================================
HOW TO UPLOAD TO GITHUB USING GITHUB DESKTOP
================================================

Your project is now ready to upload! Follow these steps:

STEP 1: Open GitHub Desktop
----------------------------
- Launch GitHub Desktop on your PC
- If you're not signed in, sign in with your GitHub account

STEP 2: Add This Repository
----------------------------
1. Click "File" menu → "Add Local Repository"
2. Click "Choose..." button
3. Navigate to: C:\Users\brand\Desktop\Key Legacy (website)
4. Click "Add Repository"

GitHub Desktop should now show:
✅ Repository: Key Legacy (website)
✅ Current Branch: master
✅ 1 commit ready

STEP 3: Publish to GitHub
----------------------------
1. Click the "Publish repository" button (top right)
2. In the dialog that appears:
   - Name: Key-Legacy-Realty-Website (or whatever you prefer)
   - Description: Professional rental property website for Key Legacy Realty
   - ⚠️ IMPORTANT: UNCHECK "Keep this code private" if you want it public
   - Leave organization as your personal account
3. Click "Publish Repository"

STEP 4: Enable GitHub Pages (To View Website Online)
----------------------------------------------------
1. Go to GitHub.com in your browser
2. Navigate to your repository
3. Click "Settings" tab
4. Scroll down to "Pages" section (left sidebar)
5. Under "Source":
   - Branch: master
   - Folder: / (root)
6. Click "Save"

⚠️ IMPORTANT FOR GITHUB PAGES:
The website files need to be in the root OR you need to configure the path.

Since your HTML files are in the "public/" folder, you have 2 options:

OPTION A: Move files to root (Easiest)
---------------------------------------
Move all files from public/ to the root directory.
This way GitHub Pages will find index.html immediately.

OPTION B: Configure custom path
--------------------------------
Keep the structure as-is and configure GitHub Pages to serve from /public folder.
(This requires editing repository settings)

STEP 5: View Your Website
--------------------------
After enabling GitHub Pages:
- Wait 1-2 minutes for GitHub to build your site
- Your website will be live at:
  https://[your-username].github.io/[repository-name]/

For example:
https://frogqween.github.io/Key-Legacy-Realty-Website/

================================================
TROUBLESHOOTING
================================================

If repository doesn't show up in GitHub Desktop:
- Make sure you selected the correct folder
- The folder should show a .git folder (might be hidden)

If GitHub Pages shows 404:
- Make sure index.html is in the root OR
- Configure Pages to serve from /public folder
- Wait a few minutes after enabling Pages

If you need to make changes:
1. Edit files locally
2. Open GitHub Desktop
3. It will show your changes
4. Write a commit message
5. Click "Commit to master"
6. Click "Push origin" to upload changes

================================================
RECOMMENDED NEXT STEPS
================================================

After uploading, you might want to:
1. Move public/index.html to root for GitHub Pages
2. Add a custom domain (optional)
3. Enable HTTPS (automatic with GitHub Pages)
4. Update property listings in data/properties-source.js

Your website is ready to go live! 🚀
